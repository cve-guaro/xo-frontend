# 5. Application Security Measures
# ============================================================
# Authentication:
#   - Phone-based OTP via GeezSMS
#   - JWT token-based session management
#   - Token expiry and refresh mechanism
#
# Rate Limiting:
#   - General API: 500 req / 15 min per IP
#   - Payment endpoints: 5 req / 1 min per IP
#   - Auth endpoints: 500 req / 15 min per IP
#   - Profile polling: 60 req / 1 min per IP
#
# CORS Policy:
#   - Hardcoded origin whitelist (no dynamic reflection)
#   - Allowed: xoethiopia.com, www.xoethiopia.com, *.vercel.app
#   - Credentials: enabled
#
# Financial Security:
#   - Idempotency keys on all transactions
#   - Two-step commit for withdrawals (DB reserve -> API call)
#   - Automatic rollback on failed Chapa payouts
#   - Admin manual review for withdrawals > 2,000 ETB
#   - Webhook signature verification (HMAC-SHA256)
#   - Balance-locked during pending transactions
#
# Anti-Cheat:
#   - Server-side game state validation
#   - Turn timer enforcement (30s)
#   - Move validation against board state
#   - Anomaly scoring for suspicious behavior
#
# Data Protection:
#   - All data encrypted in transit (TLS 1.3)
#   - Database hosted on Supabase with row-level security
#   - No sensitive data in client-side storage
#   - Phone numbers normalized and validated
